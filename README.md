# یوم‌تایم — Yom Time

**اوقات شرعی دقیق برای هر نقطه از جهان**

محاسبه اوقات نماز، طلوع و غروب خورشید با پشتیبانی کامل از تقویم جلالی (شمسی) و میلادی.

---

## ویژگی‌ها

- محاسبه دقیق اوقات شرعی (فجر، طلوع، ظهر، عصر، مغرب، عشا)
- محاسبه **یک‌سوم شب** و **دو‌سوم شب**
- پشتیبانی کامل از **تقویم جلالی**
- دیتابیس بیش از ۱۷۰ هزار شهر جهان
- موقعیت‌یابی با GPS یا ورود دستی مختصات
- خروجی PNG، PDF و اکسل
- اعلان محلی برای اوقات نماز
- کار آفلاین با فرمول‌های نجومی محلی
- اعتبارسنجی با منابع معتبر (USNO و sunrise-sunset.org)

## روش‌های محاسبه (در حال توسعه)

- محاسبه محلی (فرمول‌های نجومی)
- Muslim World League
- Umm al-Qura
- Egyptian General Authority
- ISNA
- و روش‌های دیگر...

## نصب و اجرا

### وب
```bash
npx serve www
```

### اندروید (Capacitor)
```bash
npm install
npx cap add android
npx cap sync
npx cap open android
```
